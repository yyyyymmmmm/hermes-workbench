# Hermes Personal Workbench

真实服务入口为 `http://127.0.0.1:4317`。正式界面复用用户认可的 `ui/terminal/styles.css` 和 `ui/terminal/views.js` 导航与布局，通过 `web/original-ui.js` 接入真实状态，保留三栏工作台、工作空间、健康、能力中心与助手入口。未接入功能不展示虚构数据或模拟成功。

`ui/index.html` 仍保留为独立设计原型。真实服务不加载原型的 `store.js`、`app.js` 或模拟对话逻辑，不读取原型 localStorage。登录、注册、任务、日历、设备与 Hermes 管理使用 `web/app.js` 的真实 API。`web/styles.css` 是旧简版样式，正式入口已不再加载。

## 本地运行

需要 Node.js 24。首次运行 `npm ci`，根据 `.env.example` 创建服务器专用的 `.env.local` 并填写验证服务配置，然后 `npm start`。仓库不包含应用密钥、用户数据或本机部署配置。

```powershell
npm start
npm test
npm run test:e2e
npm run auth:probe
npm run backup
```

如果 Node 不在 PATH，可调用本机工具链：

```powershell
& 'C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' --env-file-if-exists=.env.local server/main.mjs
```

浏览器测试默认使用本机 bundled Playwright；其他机器设置 `PLAYWRIGHT_PATH` 为已安装的 Playwright 模块路径。测试使用独立临时数据库和注入的上游桩；生产入口没有测试账号或免登录开关。

## 已实现

- 对话体验：历史会话按需展开，权限使用次级弹层；独立消息滚动、固定自适应输入区、用户消息与助手正文分层、流式安全 Markdown、回复复制、回到最新消息。Enter 发送，Shift+Enter 换行，中文输入法确认不发送；生成中可起草下一条，但不自动排队发送。保留会话授权、审批和中断流程。

- 模型可在 Hermes 管理页刷新、搜索并「应用到新会话」，确认后写入共享 default 档案并回读验证；现有会话保持原模型，高费用授权默认关闭。此功能替代了原 UI 的仅保存偏好入口，不等于会话热切换。
- 能力中心新增 Skills Hub：官方来源搜索、分页、正文/文件预览、安全扫描、确认安装与回读。危险或不明确扫描禁止安装；未知安装结果须重新核对。外部 URL/仓库安装和自动升级未开放。

- 对话任务落地：输入区的「起草任务清单」准备提示词但不自动发送；成功完成的回复可点「安排为待办」，识别最多 30 条 Markdown 未完成复选项。逐项审核/修改、选择项目并显式安排时间后批量提交；整批事务、幂等重试、来源去重，任务可返回原对话。时间不从自然语言猜测，未填时间的任务不进入日历。不是 Hermes 自主调用工作台工具。
- 当前数据库版本为 6；升级前执行在线备份。任务来源与导入回执持久化，删除任务也不会自动重新导入同一来源项。

- 项目工作空间：创建、编辑、搜索、归档和恢复；关联现有任务与文档，项目内新建任务与关联在同一事务提交。时间安排和完成状态复用待办/日历原始记录。文档直接进入现有编辑器；项目上下文经确认后作为只读附件加入 Hermes，不自动发送或授予写权限。项目修改有版本冲突保护，可查看服务器版本并保留本地文字后重新保存。项目表从版本 5 引入，当前数据库版本为 6，升级前运行备份。

- 真实对话：`server/gateway.mjs` / `server/runs.mjs` / `web/chat.js` 支持默认档案会话、流式回复、执行历史、中断及网关审批。每次发送须确认远端执行权限；不自动附带任务与健康数据。未知结果不重发，支持远端状态核对和显式结束本地跟踪。
- 在线备份：`npm run backup` 生成 `.runtime/backups/snapshot-*`，包含 SQLite 快照、`vault.key` 和校验清单。失败的未完成目录不得用于恢复。备份含私密数据与解密密钥，必须按敏感数据保护；此命令不会自动上传异地。

- 平台账号登录：适配已有 PHP `userlogon`，校验 nonce/check、时间窗口和返回身份。本系统建立自己的 HttpOnly 会话，不将上游登录结果当作访问令牌。
- 注册：适配应用账号 `userreg`，校验账号/密码/QQ 与重复密码；真实注册成功后返回登录，不自动创建已认证会话。遵循上游 5–11 位账号、6–18 位密码限制。QQ 仅作上游要求的联系字段，未经所有权验证，不是本系统的身份凭据。
- 找回密码入口已提供，但应用账号自助重置尚不可用。源码 `api/user/czpass.php` 操作的是开发者 `yixi_user`，不是应用账号 `yixi_appuser`；不能混用。需在验证服务增加应用账号所有权验证、一次性短期令牌、发送限流、原子消费及重置后会话撤销后才能启用。当前不会发送验证码或声称密码已重置。
- 应用用户、任务、设备会话、Hermes 连接与模型偏好按用户隔离。
- 任务和日历使用同一条服务端记录。支持增改删、完成、时间安排、时区、版本冲突、幂等保存、增量读取和删除标记。
- 多浏览器/多设备共享同一个服务端数据库。网页每 15 秒同步，可手动同步；同源窗口通过 BroadcastChannel 通知更新。编辑中保留输入，提交时检测冲突。
- 每用户填写 Hermes HTTPS 根地址、用户名和密码；验证网关登录，保存加密 cookie jar，不保存远端密码。
- 动态获取网关模型目录，过滤未认证提供商，保存工作台模型偏好。另有显式确认的默认模型应用接口；**只保存旧偏好接口仍不等于修改远端模型。** 无兼容接口时返回明确错误，不编造目录。
- 设备列表与会话撤销、平台退出登录、Hermes 断开。Hermes 断开尽力撤销远端会话；失败仍移除本地凭证并提示。
- 浏览器支持时可语音输入任务名称；不代表已实现语音 AI 通话。

## 安全边界

应用密钥只保存在服务端 `.env.local`；上游密码只存在登录请求生命周期内。会话令牌在数据库中保存 SHA-256 摘要，Hermes cookie jar 采用 AES-256-GCM，并以用户 ID 作为 AAD。`vault.key` 与数据库一起保存在受保护目录，丢失密钥需要重新连接 Hermes。

Windows 的文件 `mode` 不能替代 NTFS ACL。上线时必须使用专用服务账号，仅授权该账号和管理员访问 `.env.local`、数据库和密钥；应用不具备抵抗服务器管理员或完全控制本机攻击者的能力。任务数据当前不是端到端加密。

请求使用 Origin 校验、CSRF token、输入限制、限流、响应大小限制和超时。远端连接逐次解析 DNS 并固定连接 IP，禁止自动重定向；用户 URL 不得包含账号、路径、查询或片段。私网仅允许部署者显式填写 `HERMES_PRIVATE_HOSTS` 中的准确主机名/IP，元数据、链路本地等仍禁止。不要将不受信任域名加入允许列表。

本机代理 DNS 将域名映射到 `198.18.0.0/15`。仅固定、由管理员配置的验证服务允许此 Fake-IP 路径，仍强制 HTTPS 证书验证。**用户提供的 Hermes 地址没有这个例外**；请为 Hermes 域名配置真实 DNS/代理直连规则，否则会返回 `BLOCKED_ADDRESS`。不要为通用代理关闭 SSRF 防护。

`HERMES_PRIVATE_HOSTS` 也支持 `主机:端口`，可将局域网权限缩小到指定服务。请按自己的部署显式配置允许列表，不要放行整个私网。HTTP 仅适合可信局域网测试，正式部署应启用 HTTPS。

只读联调可在交互终端运行 `node server/scripts/hermes-probe.mjs https://hermes.example.com your-username`，随后隐藏输入密码。脚本使用临时隔离数据库，验证登录和模型发现，尝试退出远端会话并删除临时数据，不发送模型推理请求、不修改网关配置。

静态资源只有明确列出的资源路由，服务不会暴露 `.env`、原始 PHP 源码或数据库。提供的 `api/` 目录含既有部署信息，已加入忽略列表，未修改或重新发布。

既有验证服务比较明文密码，且 `check` 不覆盖完整响应体，因此依赖 HTTPS 保护；应用无法修复上游的密码存储。商用前应升级验证服务密码哈希、账户级抗爆破、账号恢复与注销能力。登录返回的 VIP 字段不是经过校验的订阅权益，本版没有将其用于授权。

## 多设备部署

`127.0.0.1` 仅供本机访问。要让 Windows、安卓和 iOS 访问相同数据，必须部署一个固定 HTTPS 工作台服务；只接入验证服务不会自动同步工作数据。

1. 将工作台服务部署到受控服务器，配置同一 `AUTH_BASE_URL`、App ID 与服务端密钥。
2. 使用反向代理终止 TLS；Node 绑定 loopback。设置 `PUBLIC_ORIGIN=https://你的工作台域名`、`SECURE_COOKIES=true`，代理保留 Origin，不暴露 Node 端口。
3. 保护 `.runtime` 和 `.env.local`。当前为单实例 SQLite WAL，不能将 SQLite 放在多个实例共享的网络文件系统上。
4. 维护备份和恢复演练。暂停服务后一起备份数据库及其 WAL/SHM（若存在）和 `vault.key`，或者采用 SQLite 在线备份 API；不可运行中只复制主数据库文件。不要将密钥放到公开备份。
5. 生产部署增加反向代理限流、TLS/HSTS、监控、告警、灾难恢复、账户注销/导出/保留周期与隐私声明。共享出口下按 IP 限流需在可信代理配置下审慎调整。

本版不支持离线编辑队列，不会把离线保存伪装为成功；网络失败时表单保留，重复保存复用幂等键。移动端目前是响应式网页，没有 Android/iOS 原生安装包；Windows 已有内测便携客户端。

注册经工作台服务端转发，上游可能触发同 IP 仅能注册一次的旧规则（117）。商用前需在验证服务建立可信 BFF 调用机制和独立的反滥用策略，不能靠伪造客户端 IP 绕过。注册请求不自动重试；网络中断时可能已在上游创建账号，可先尝试登录。

## 设置与 Windows

侧栏“设置”提供极简白、夜间、腾讯蓝、网易红、哔哩粉五种主题，中文/英文切换与减少动画；主题名仅描述配色，不代表相关品牌合作。设备偏好存储于浏览器或桌面客户端的 localStorage，不存放密钥。语言切换会重载，未保存内容先确认；用户文本不会翻译。

Windows 便携入口：`dist/Hermes Workbench-win32-x64/Hermes Workbench.exe`。需保留整个目录，不能只移动 exe。首次选择工作台服务地址（本机为 `http://127.0.0.1:4317`），不是 Hermes NAS 网关地址。客户端不启动或打包含应用密钥的工作台后端；跨设备使用需部署自己的 HTTPS 工作台服务。可用 `npm run desktop:dev` 启动工程，`npm run desktop:build` 构建；当前未签名，无自动更新，不是正式发行安装包。

Windows 使用隔离、沙箱化渲染进程，网页无 Node 权限，外部链接需确认后由系统浏览器打开，设备权限默认拒绝。平台登录凭证由 Chromium 会话管理，不在客户端嵌入验证服务密钥。

Hermes 管理页可读取工具集、Skills、MCP、记忆、定时任务和语音配置。记忆开关/字符上限/压缩、语音服务商/识别开关/音色支持确认保存和回读验证，失败保留草稿；只发送允许修改的字段，不写回密钥。能力中心展示真实 MCP 目录，支持无需密钥、无需引导安装的 HTTP 条目，默认停用，安装后需另行授权和启用；不代表已经能够调用。Skills/MCP 启停、任务暂停/恢复同样需要确认。上述写入通过隔离协议测试，未擅自修改真实 NAS。

能力目录已接入 OAuth 发起、授权链接、状态检查和取消；连接测试通过后可启用，失败不会自动开启。支持移除及回读验证；移除不等于撤销第三方授权。授权流程刷新页面可继续，服务器重启后需等待远端流程过期再发起。启用不保证已存在会话立即加载工具，不会擅自重启网关。相关行为通过隔离协议和浏览器测试，第三方真实授权仍待用户验收。

任务与日历通过“工具权限 > 工作台上下文”选择快照，预览后发送；文档显式附加。并非全面自动读写工具。Skills Hub 官方来源已接入预览、复扫、确认安装和来源验证；固定包版本、持久化安装作业、工具集编辑、连续语音仍待实现。

## 对话与文档

能力中心已按发现、已添加 MCP、已安装 Skills 分页，每页 10 条，支持名称/描述搜索及启用状态筛选。连接与数据页可添加外部 HTTPS MCP（无认证或 OAuth）；不接受命令执行、URL 内凭证或查询参数，重复名称不覆盖。网络与权限还需由 NAS 执行出站策略。会话标题与消息搜索支持全部工作台本地历史，20 条分页，不限于最近 100 条下拉列表。

Asana 的真实连接测试确认 NAS 缺少 `mcp.client.streamable_http`，页面已提供明确诊断。未擅自升级 NAS 依赖。参考项目调研与商业许可边界见 [REFERENCE_REVIEW.md](REFERENCE_REVIEW.md)。

工作空间已接入服务端文档存储：新建、文本导入、编辑、搜索、Markdown 安全预览、下载、版本历史、回收站、恢复和彻底删除。完成的 Hermes 回复可保存为文档，文档可显式附加到聊天输入框，不自动发送。代码文件目前仅编辑文本，不运行命令或关联仓库。

文档保存使用版本比较与持久化幂等键；多窗口冲突保留本地内容，允许查看服务器版本、重新载入或另存副本。每账户最多 200 份文档（含回收站），历史快照总计 20 MiB，每份 64 KB，保留最近 20 个版本。草稿保留在当前页面内存中，不使用 localStorage 存储文件；未保存离页会提示。彻底删除不清除聊天附件、远端副本或既有备份，也不等同磁盘安全擦除。

对话面板支持展开、同页历史、较早消息分页、独立滚动和会话级可撤销授权。远端工具审批仍需独立确认，撤销授权不会停止已运行任务。

可选择或拖入 Markdown、UTF-8 文本和代码文件，每个最多 64 KB、共 5 个且总计 192 KB。附件与消息一起持久化并作为参考文本发给 Hermes，不会写入远端文件路径。支持 Markdown 安全预览、源码和下载；PDF、图片、Office 尚不支持。附件在工作台数据库内明文保存，不是端到端加密。
